# 星轨节奏 Starline Beat

## 项目简介

本项目选题为 **10. 音乐节奏游戏（3D/霓虹视觉风格）**。作品以网页小游戏的形式呈现，玩家需要在音符下落到判定线附近时按下对应按键，系统会根据按键时机给出判定并计算分数、连击数和准确率。

游戏整体采用星空与霓虹风格，界面包含曲目选择、四条音轨、动态音符、实时数据面板、进度条和结算评级，能够完整展示一个音乐节奏类小游戏的核心流程。

## 文件结构

```text
rhythm_star_game_separated/
├── index.html   网页主体结构
├── style.css    页面样式和动画
├── game.js      游戏核心逻辑
└── README.md    说明文档
```

本项目为前端网页小游戏，主要逻辑写在 `game.js` 中，页面结构与样式分别由 `index.html` 和 `style.css` 负责。

## 如何运行

解压项目文件夹后，直接双击：

```text
index.html
```

即可在浏览器中运行，不需要安装 Python、Node.js 或其他额外环境。

## 玩法

游戏开始后，音符会从上往下移动。音符接近发光判定线时，按下对应按键：

```text
D   F   J   K
```

也可以直接点击屏幕底部的 D/F/J/K 按键进行操作。

完整键盘操作如下：

```text
Space / Enter  开始游戏或继续游戏
D / F / J / K  击打对应轨道的音符
P              暂停或继续
R              重新开始当前模式
M              开启或关闭背景音乐
1 / 2 / 3 / 4 选择对应曲目
[ / ]          切换上一首或下一首
```

## 已实现功能

- 多曲目选择：内置 Neon Classroom、Starlight Run、Moon Circuit、Comet Drive 四首曲目。
- 曲目差异：不同曲目拥有不同速度、旋律、低音、和声和谱面密度。
- 四轨谱面生成：音符按照音乐节拍表出现在四条轨道中，每条轨道对应一个键位。
- 同步下落动画：每个音符会提前出现，并在对应音乐节拍到达判定线。
- 键盘完整控制：支持 Space / Enter 开始或继续，P 暂停，R 重开，M 开关音乐，1-4 或 [ ] 选曲，D/F/J/K 击打音符。
- 鼠标辅助操作：也可以点击屏幕底部的 D/F/J/K 按键完成操作。
- 循环背景音乐：使用 Web Audio API 生成旋律、低音和和声，不依赖外部音乐文件。
- 音乐开关：支持通过 M 键或页面按钮开启、关闭背景音乐。
- 按键视觉反馈：按下键盘或点击按钮时，对应轨道和按键会高亮。
- 节奏判定系统：根据按键时机显示 Perfect、Great、Good、Miss。
- 得分系统：不同判定获得不同分数，连续命中会增加额外得分。
- 连击系统：连续命中会累积 Combo，失误后 Combo 清零。
- 数据统计：实时显示分数、连击、准确率、命中数、失误数和最高分。
- 暂停与继续：游戏过程中可以随时暂停，暂停后继续时进度不会跳变。
- 练习模式：提供较慢速度，便于熟悉按键节奏。
- 结算评级：游戏结束后显示评级、总分、准确率、命中数、失误数和最高连击。
- 本地最高分保存：浏览器会分别记录每首曲目的历史最高分。
- 星空霓虹视觉界面：包含星空背景、发光轨道、判定线、动态反馈和进度条。
- 简单节拍音效：击打、失误和节拍会产生基础音效，增强节奏感。

## 设计说明

本作品围绕“音乐节奏游戏”的基本体验进行设计，重点实现曲目选择、音符生成、下落动画、循环背景音乐、键盘控制、暂停继续、节奏判定、得分统计、连击反馈和游戏结算。玩家可以全程通过键盘完成操作，打开网页后即可开始游玩，能够体现前端页面结构、样式设计、Web Audio 音频生成与 JavaScript 交互逻辑的综合应用。
